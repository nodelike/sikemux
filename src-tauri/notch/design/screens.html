Sikemux Notch

The island over the MacBook notch: what it shows, when it changes and what you can set. Each state has an id (C1) and a card with its trigger, its content and its measured size. Settings are marked option. Everything is drawn at 1:1, one CSS pixel per point, from this MacBook Pro's real notch (221 × 38 pt).

Numbers for the SwiftUI port

WindowNon-activating NSPanel, borderless, level .mainMenu + 3, joins all Spaces, stationary, full-screen auxiliary, never key or main. Fixed 760 × 560 transparent canvas pinned to the top centre of screen.frame; only the shape animates.
Notch geometryWidth = frame.width − auxiliaryTopLeftArea.width − auxiliaryTopRightArea.width, height = safeAreaInsets.top. Centre on the gap between the two areas, not on the screen. No notch: height = menu bar (frame.maxY − visibleFrame.maxY).
ShapeTop corners curve outward into the menu bar, bottom corners inward. Radii (top / bottom): closed 6 / 14, peek 14 / 22, open 19 / 24. Both radii animate with the size.
AgentsThe list is every open agent in the device view's chats and agent sessions, in their attentionRank, the order the rail and phones show; agents on other hosts the inbox lists follow. The island never ranks them itself. Each takes its state and words from its first inbox item, and the working count still drives the closed wing. It adds what the inbox leaves out: a permission's three option ids from attentions, a question's answers and the lead it went to first from the core's questions call, and each chat's subagents and shells from chats.
Closed wingsEach wing is as wide as what it holds. The left holds the marks of the first three items in the inbox, then +N. The right fits a mark for each state some item is in: needs you, then working (the core's count of agents at work), then the subagents and the shells or monitors running across every agent, then done (to review or finished), each state with its count above one and the two totals always with theirs, 10 pt apart. The island moves aside by half the difference so the camera stays between them. Bare agent marks at 20 pt, as the project tree draws them, 3 pt apart from overlapping.
Open680 wide, 560 on a display without a notch, where the header is 38 tall so its controls clear the screen edge; height follows content up to 400, then the list scrolls. Padding: top-radius horizontally, then 12. Rows are one line, 36 tall, radius 12: mark at 20 pt as the rail draws it, task, project, time, state. A label wherever the tier changes.
SpringsOpen spring(response: 0.42, dampingFraction: 0.8). Close spring(response: 0.45, dampingFraction: 1.0). Hover (shadow) interactiveSpring(response: 0.38, dampingFraction: 0.8).
ContentOne shape: the band beside the camera swaps the wings for a header in place, out of and into a 20 pt blur; the body below enters with scale 0.8 → 1 anchored at the top and opacity 0 → 1 over 0.35 s (.smooth). Agent marks fly from the wings to their rows (matchedGeometryEffect). The width is set per state (open 680, permission 460), so width, height and both radii spring together.
TimingHover 0.3 s before opening a closed island or a finished peek; a permission peek keeps its size under the pointer so its buttons stay put. Leave closes after 0.1 s, a peek too, unless the prompt holds the keyboard with a draft or files in it; clicking another app closes it and keeps the draft. A permission peek ends as soon as the request is answered anywhere, and a finished peek never replaces it. The keyboard is taken only when the prompt is clicked or New agent is chosen, never on hover. Permission peek 6 s, finished peek 3 s. A device asking to connect opens the island at 560 wide with the open radii, ignores the pointer leaving, and closes only once answered, lapsed or swiped away.
HoverShadow on (black 70%, radius 6); the size stays. A trackpad tick (.alignment) when the pointer reaches a closed island.
SwipeTwo fingers down over a closed island open it, up over an open one or a peek close it, once they travel 140 pt along the finger direction (twice the other axis; a mouse wheel's lines count 8 pt). While pulling, the island scales from the top, 1% per twentieth of the way, never under 60%, and ticks when it crosses. A list that scrolls, or an open picker, keeps the upward swipe.
HapticsA trackpad tick when the pointer reaches the closed island, a swipe crosses, a permission request peeks in, a dragged file opens the drop targets or snaps onto one. Off with the Haptic feedback option.
Hit areaThe drawn shape plus the menu-bar band beneath a closed island. Everything else in the canvas passes clicks through.
DisplaysOne panel per screen, keyed by display UUID, rebuilt when the screen setup changes. Setting: every display / the built-in only / the one under the pointer. In a full-screen app the island stays hidden unless an agent needs you.
IconsThe app's own set from shared/ui/Icons.tsx: a 16-pt grid, 1.4 stroke, round caps and joins. Port each path as a SwiftUI Shape (or an SVG asset) so the island and the app never drift apart. Agent marks come from the same file.
BuddiesEach agent in the inbox carries the face the core gave it, or none while it shows its agent's mark. A face replaces the mark at the mark's size, in the closed wing, the peeks, the rows and the drop target. The helper draws it with the app's own buddy script (Buddies.generated.swift) in JavaScriptCore and shows the SVG it returns with NSImage. Needs you waits, working works, done and failed show done and error. They bob, hop and shake as a whole as the app's do, unless the device view's faceStyle turned motion off or the Mac asks for less; eyes and sparkles stay still.
YoloLabel: Text("YOLO").foregroundStyle(LinearGradient(colors: [acc, cmd, danger, warn, live, acc])). Ring: a 1-pt strokeBorder of the same gradient whose start point slides one full turn every 5 s. The bolt stays plain accent, as in the app.
ColoursGround pure black so it merges with the camera housing. Ink #e7e5ef, dim #8b8898, faint #736f80; working #61ffca, needs you #ffca85, done and the one primary button #a277ff. Figtree for text, JetBrains Mono for commands.
