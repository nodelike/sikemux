Host backdrop

{{Logo:30}} Sikemux for iPhone

Every screen, drawn with the Mac app's own parts: the icons are rendered from src/ui/Icons.tsx, and the chat, the composer and the agent list use the same structure, words and values as the Mac's chat pane and agent rail, sized up for a thumb. The colours are Aura Noir, the default theme. The little squares, the shimmer and the amber ping are animated here as they are on the Mac.

Signing in, and connecting

The app needs a Sikemux account, and that is the only way to a host: hosts signed in to the same account show up in Devices, and the phone connects to them with the account's word for it. A phone still reaches a host only after someone at the host allows it.

Devices

Every computer this phone is paired with. With only one, the app opens straight into it and this list is one step back.

A device

A device opens on its host's name, set large over the host's backdrop, with a line above it saying it is online and what runs on it. Under the name, Agents and Terminals as two words to switch between, and the project picker at the right. Then the list as the Mac's rail draws it: rows straight on the ground under small-caps labels. Running agents keep the rail's green squares.

Project scope

The Mac's Projects header at phone size: the picker level with the tabs scopes both Agents and Terminals to a project, the way picking a project on the Mac scopes its rail. It opens the same searchable sheet as New chat, headed here by the provider filter, so the screen itself keeps only the tabs and the picker.

Starting a chat

The + at the top right was the hardest place to reach one-handed, so starting a chat moves to the bottom of the screen.

An agent

The Mac's chat pane, line for line: your messages in a bubble on the right, the agent's prose with no bubble, its thinking in faint italics, tool calls as a tree with the coloured verbs, open while the agent is still adding to them and folded to "N tool calls" once it moves on. Once a turn ends, everything before its reply folds under "Worked for 48s · 1 tool call" with a hairline under it, and a tap opens it again. Then the working line with the agent's logo breathing. The composer is the Mac's: attach, YOLO, model, effort, context ring, send or stop. What the agent still has going sits in one line docked on the composer, and opens into a sheet.

New chat

The Mac's empty chat: pick the agent from the same tiles, the project, and type into the same composer. Only launchers the host publishes appear.

A terminal

The host's own terminal in xterm.js, with a key row for what the phone keyboard lacks.

Away from the app

An agent stops to ask while the phone is in a pocket. The host seals what happened with a key only this phone has, and Sikemux passes it on without being able to read it. By default a host notifies only while nobody is at it.
