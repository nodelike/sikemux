Host backdrop

{{Logo:30}} Sikemux for iPhone

Every screen, drawn with the Mac app's own parts: the icons are rendered from shared/ui/Icons.tsx, and the chat, the composer and the agent list use the same structure, words and values as the Mac's chat pane and tab rail, sized up for a thumb. The colours are Aura Noir, the default theme. The little squares, the shimmer and the amber ping are animated here as they are on the Mac.

Signing in, and connecting

The app needs a Sikemux account, and that is the only way to a host: hosts signed in to the same account show up in Devices, and the phone connects to them with the account's word for it. A phone still reaches a host only after someone at the host allows it.

The lock

Off until the person turns on Lock Sikemux in the account sheet. Then a signed-in phone shows no host, chat or device, and opens no link or notification, until the person passes Face ID, Touch ID or the phone's passcode. Signing in on the phone counts; nothing is asked of a phone that is signed out.

Devices

Every computer this phone is paired with. With only one, the app opens straight into it and this list is one step back.

A device

A device opens on its host's name, set large over the host's backdrop, with a line above it saying it is online and what runs on it. Under the name, Agents, Terminals and Board as words to switch between, and the project picker at the right. Then the host's open agents in one list, straight on the ground, ranked by the host's core the same way the Mac's rail and the notch list them, and its recent chats under them. Running agents keep the rail's green squares.

Letting hosts and phones in

The phone answers for its owner what used to wait at the computer: a host with no browser is added to the account by its code, and a phone asking to connect to a host, or another host asking to link with it, is let in, or not, from another phone already on the account with full control.

The board

Each project's board, the one agents plan their work on and Auto runs, read on the phone. Board joins Agents and Terminals on the host's bar. It only reads: cards move on the Mac, or by the agents themselves.

Project scope

The Mac's Projects header at phone size: the picker level with the tabs scopes both Agents and Terminals to a project, the way picking a project on the Mac scopes its rail. It opens the same searchable sheet as New chat, headed here by the provider filter, so the screen itself keeps only the tabs and the picker.

Starting a chat

The + at the top right was the hardest place to reach one-handed, so starting a chat moves to the bottom of the screen.

An agent

The Mac's chat pane, line for line: your messages in a bubble on the right, the agent's prose with no bubble, its thinking in faint italics, tool calls as a tree with the coloured verbs, open while the agent is still adding to them and folded to "N tool calls" once it moves on. Once a turn ends, everything before its reply folds under the agent's logo and "Worked for 48s · 1 tool call" with the Mac's rule under it, or "Thought for 3s" when the turn only thought, and a tap opens it again; one opened stays open after leaving the chat and coming back. Then the working line with the agent's logo breathing. No line runs under the header: the transcript fades out under it and above the composer, over the backdrop. The composer is the Mac's: attach, YOLO, model, effort, context ring, send or stop. What the agent still has going sits in one line docked on the composer, and opens into a sheet.

Sharing to Sikemux

Sikemux is in every app's share menu. What is shared goes to a chat's composer, unsent, or to the Stash, which keeps it for later on the account, so every signed-in device and host sees it. One sheet does both: what is being shared on top, a note under it, the chats used last, and Stash at the bottom.

Stash in the composer

The stash has its own button in the composer's bar, as on the Mac. It lists what the account has stashed and not yet used, newest first, from any device, and takes the whole prompt in too. An item picked rides with the message as a preview chip.

Mentions in the composer

As on the Mac, a word that starts with @, +, # or ! opens one menu over the composer, under the kinds of thing it names, and a tap on a kind turns the word into that one. A pick goes into the draft as a chip, coloured apart from the words around it, that a backspace into takes out whole, and that is kept with the draft on the host, so it follows the person to the Mac. The message sends what each chip stands for: an agent or chat for the host to describe, a file or folder as an attachment, an issue's or pull request's text.

New chat

The Mac's empty chat: pick the agent from the same tiles, the project, and type into the same composer. Only launchers the host publishes appear.

A chat in a worktree of its own

As on the Mac, before the first message a pill at the end of the project strip says whether the chat starts in a new git worktree on a branch of its own. It shows only for a project in a git repository, and starts as the person last chose for that project. Flipping it keeps the choice for the project on the host, for the Mac and every phone.

A terminal

The host's own terminal in xterm.js, with a key row for what the phone keyboard lacks.

A shared chat

Someone shared a chat with a link, and it opened here. It is the agent screen with nothing to press: no composer, no menu, no answers to give. The transcript arrives from the accounts server, sealed by the sharer's computer, and pages back through the turns before the link was made. Where the composer would be, one line says it is read-only and how long the link lasts.

Away from the app

An agent stops to ask while the phone is in a pocket. The host seals what happened with a key only this phone has, and Sikemux passes it on without being able to read it. By default a host notifies only while nobody is at it.
