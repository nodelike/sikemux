{{Logo:30}} Sikemux for iPhone

Every screen, drawn with the Mac app's own parts: the icons are rendered from src/ui/Icons.tsx, and the chat, the composer and the agent list use the same structure, words and values as the Mac's chat pane and agent rail, sized up for a thumb. The colours are Aura Noir, the default theme. The little squares, the shimmer and the amber ping are animated here as they are on the Mac.

Pairing

A phone reaches a Mac only after someone at the Mac approves it. A code scanned or a link pasted inside Sikemux goes straight to "Approve on your Mac". A link opened from anywhere else, such as the iPhone's own Camera, first asks whether to pair.

Devices

Every computer this phone is paired with. With only one, the app opens straight into it and this list is one step back.

A device

The Mac's agent rail at phone size: a switch for agents or terminals, the provider filter, then what needs you lifted above everything else. Running agents keep the rail's green squares.

Project scope

The Mac's Projects header at phone size: one pill under the device scopes both Agents and Terminals to a project, the way picking a project on the Mac scopes its rail. It opens the same searchable sheet as New chat.

Starting a chat

The + at the top right was the hardest place to reach one-handed, so starting a chat moves to the bottom of the screen.

An agent

The Mac's chat pane, line for line: your messages in a bubble on the right, the agent's prose with no bubble, its thinking in faint italics, tool calls folded to "N tool calls" and opened as a tree with the coloured verbs, and the working line with the agent's logo breathing. The composer is the Mac's: attach, YOLO, model, effort, context ring, dictate, send or stop.

New chat

The Mac's empty chat: pick the agent from the same tiles, the project, and type into the same composer. Only launchers the Mac app publishes appear.

A terminal

The Mac's own terminal in xterm.js, with a key row for what the phone keyboard lacks.

Away from the app

An agent stops to ask while the phone is in a pocket. This needs a push service the core can reach, which does not exist yet.
