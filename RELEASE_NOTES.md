# Sikemux v0.6.2

Two days and about 470 changes after 0.6.1. Agents reach each other across your hosts, the app speaks eight more languages again, and the download is smaller.

## What's new

- **Your hosts, one place.** Search chats on every linked host, see their hits in Recent, @mention an agent on another host, and let agents read and message agents wherever they run.
- **Eight languages are back.** French, Spanish, German, Chinese, Japanese, Korean, Russian and Portuguese, each reviewed again.
- **Tasks.** A Tasks view on the desk replaces the Agent Board, with one list of what was handed on.
- **Calls.** The agent that raised a call can edit or withdraw it, Shift+Enter sends a note and keeps the call open, and the bell and the Devices gauge carry corner badges.
- **Chats.** Reply to one paragraph of an answer, long model pickers list your recent models first, and the line under the chat says what the project listens for.
- **Your own triggers.** Set one up from the Automation page.
- **Settings that follow you.** A switch in Settings brings your settings, skills and themes to every host you sign in on; each host keeps the theme it shows.
- **Accounts.** A new chat goes to the account whose limit refills first.
- **Smaller.** The Mac download is lighter.
- **Simpler chief chat.** The While you were away list and the Now card are gone.

Also fixed: Chinese text draws on Linux, the welcome screen opens the first chat on the agent you picked, an agent's start error shows in full, and a code block inside a list item stays whole.

For the complete patch history, compare [`v0.6.1...v0.6.2`](https://github.com/nodelike/sikemux/compare/v0.6.1...v0.6.2).
