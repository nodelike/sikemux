# Sikemux v0.5.1-nightly.7

The seventh nightly on the 0.5.1 line. Nightlies are signed and delivered exactly like stable releases, but they carry unreleased work and can break. Switch back to stable in Settings → About whenever you want; you keep the build you are on until a stable release passes it.

## New since nightly.6

- **The editor has its own tab again.** Files in the side rail and ⌘⌥1 open the editor with its file tree inside it, as before nightly.5, and an editor with no files open shows its empty page instead of closing.

For the complete patch history, compare [`v0.5.1-nightly.6...v0.5.1-nightly.7`](https://github.com/nodelike/sikemux/compare/v0.5.1-nightly.6...v0.5.1-nightly.7).
