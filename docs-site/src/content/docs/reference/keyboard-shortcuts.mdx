These are the defaults. Change any of them in **Settings → Keybindings**, and search every action with the command deck (`⌘⇧P`).

## Workspace

| Action | Shortcut | What it does |
|---|---|---|
| Open command deck | `⌘⇧P` | Search every action, shortcut, and custom command |
| Open file or request palette | `⌘P` | Files in projects, or what the plugin in front offers |
| Global search | `⌘⇧F` | Search across the active project |
| Open settings | `⌘,` | Open or close this preferences window |
| Focus mode | `⌘B` | Hide both rails |
| Open project | `⌘O` | Open the project picker |
| Open project, host or plugin | `⌘⇧O` | Pick from projects, SSH hosts and plugins in one list |
| Connect to SSH host | `⌘⇧S` | Open the SSH host picker |
| Close session | `⌘⇧W` | Close the project, host or terminal session in front, asking first if agents would stop |
| Increase text size | `⌘=` | Larger text in the focused editor or chat, or in every terminal |
| Decrease text size | `⌘-` | Smaller text in the focused editor or chat, or in every terminal |
| Reset text size | `⌘0` | Return the focused editor or chat, or every terminal, to its default size |

## Agents

| Action | Shortcut | What it does |
|---|---|---|
| New agent | `⌘N` | Start the agent you launched last in this project, ready to type to |
| Choose agent | `⌘⇧N` | Start any installed agent, or resume an earlier conversation |
| Show or hide desk | `⌘J` | The agent's pages, files and terminals, beside it |
| Toggle agent permissions | `⌘⇧Y` | Toggle skip-permissions for the active agent |

## Panes

| Action | Shortcut | What it does |
|---|---|---|
| New terminal | `⌘T` | A terminal tab in this project, another login on this host, or a new terminal under Terminals |
| Focus Terminals | `⌘⌃T` | Jump to the terminal under Terminals |
| Split pane right | `⌘D` | Create a side-by-side pane |
| Split pane down | `⌘⇧D` | Create a pane below |
| Split pane into tabs | `⌘⌥D` | Create a pane in the same place, reached by tab |
| Focus pane left | `⌘⌥Left` | Move focus to the pane on the left |
| Focus pane down | `⌘⌥Down` | Move focus to the pane below |
| Focus pane up | `⌘⌥Up` | Move focus to the pane above |
| Focus pane right | `⌘⌥Right` | Move focus to the pane on the right |
| Resize pane left | `⌘⌃Left` | Grow the active pane toward the left |
| Resize pane down | `⌘⌃Down` | Grow the active pane downward |
| Resize pane up | `⌘⌃Up` | Grow the active pane upward |
| Resize pane right | `⌘⌃Right` | Grow the active pane toward the right |
| Zoom pane | `⌘⇧↵` | Fill the window with the active pane |
| Close | `⌘W` | Close the page, file, pane or tab in front, asking first if an agent is mid-turn |
