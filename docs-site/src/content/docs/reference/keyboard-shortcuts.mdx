These are the defaults. Change any of them in **Settings → Keyboard**, and search every action with the command deck (`⌘⇧P`, or `Ctrl+Shift+P` on Linux).

On Linux a terminal keeps Ctrl with a letter, `[` or `]` for its shell while you type in it. A shortcut on one of those keys lists a second key, which runs it from a terminal too.

## Workspace

| Action | Mac | Linux | What it does |
|---|---|---|---|
| Open command deck | `⌘⇧P` | `Ctrl+Shift+P` | Search every action, shortcut, and custom command |
| Open file or request palette | `⌘P` | `Ctrl+P` or `Ctrl+Alt+P` | Files in projects, or what the plugin in front offers |
| Global search | `⌘⇧F` | `Ctrl+Shift+F` | Search across the active project |
| Open settings | `⌘,` | `Ctrl+,` | Open or close this preferences window |
| Focus mode | `⌘B` | `Ctrl+B` or `Ctrl+Alt+F` | Hide both rails |
| Open project | `⌘O` | `Ctrl+O` or `Ctrl+Shift+O` | Open the project picker |
| Open project, host or plugin | `⌘⇧O` | `Ctrl+Alt+O` | Pick from projects, SSH hosts and plugins in one list |
| Connect to SSH host | `⌘⇧S` | `Ctrl+Alt+S` | Open the SSH host picker |
| Close session | `⌘⇧W` | `Ctrl+Shift+Q` | Close the project, host or terminal session in front, asking first if agents would stop |
| Increase text size | `⌘=` | `Ctrl+=` | Larger text in the focused editor or chat, or in every terminal |
| Decrease text size | `⌘-` | `Ctrl+-` | Smaller text in the focused editor or chat, or in every terminal |
| Reset text size | `⌘0` | `Ctrl+0` | Return the focused editor or chat, or every terminal, to its default size |

## Agents

| Action | Mac | Linux | What it does |
|---|---|---|---|
| New agent | `⌘N` | `Ctrl+N` or `Ctrl+Shift+N` | Start the agent you launched last in this project, ready to type to |
| Choose agent | `⌘⇧N` | `Ctrl+Alt+N` | Start any installed agent, or resume an earlier conversation |
| Show or hide desk | `⌘J` | `Ctrl+J` or `Ctrl+Shift+J` | The agent's pages, files and terminals, beside it |
| Show desk alone | `⌘K` | `Ctrl+K` or `Ctrl+Shift+K` | Hide the agent beside its desk, or bring it back |
| Toggle agent permissions | `⌘⇧Y` | `Ctrl+Shift+Y` | Toggle skip-permissions for the active agent |
| SnapShot window to chat | `⌘⇧2` |  | Take the window you work in, in another app, to the chat as a picture with its app, title and text. Works from any app |
