Every agent Sikemux starts gets these tools through the `sikemux-tools` MCP server. The same calls work from a terminal with `sikemux tool METHOD [JSON_PARAMS]`. A tool listed with an action, such as `browser navigate`, is one tool, `browser`, called with `action: "navigate"`.

## browser

| Tool | What it does |
|---|---|
| `browser_navigate` | Go to a URL, back, forward or reload; waits for the page. |
| `browser_state` | Read the tab: url, title, numbered elements, text, tabs, downloads. |
| `browser_find` | Find elements by visible text or accessible name. |
| `browser_click` | Click an element by number, text, selector or point. |
| `browser_type` | Type into a field, replacing it or at the caret. |
| `browser_press` | Press a key or chord, such as Meta+a. |
| `browser_act` | Batch navigate, click, type, wait, read. |
| `browser_drag` | Drag from one element or point to another. |
| `browser_upload` | Give files to a file input. |
| `browser_dialog` | Answer an alert, confirm or prompt. |
| `browser_viewport` | Set this tab's viewport size or preset. |
| `browser_scroll` | Scroll to an element, by deltaY, or to an end. |
| `browser_evaluate` | Run a script in the page; returns JSON. |
| `browser_network` | List page requests with status and body. |
| `browser_console` | List page console messages and errors. |
| `browser_screenshot` | Capture the tab or the whole page. |
| `browser_annotate` | Box an element or caption the page. |
| `browser_record` | Record this tab to MP4, or stop. |
| `browser_wait` | Wait for text, a selector, a URL or quiet network. |
| `browser_switch_tab` | Switch to one of your tabs. |
| `browser_close_tab` | Close one of your tabs. |

## sim

| Tool | What it does |
|---|---|
| `sim devices` | List the simulators, the one you hold, and which other agents hold. |
| `sim attach` | Attach a simulator by name, else the warmest free one, and read its screen. |
| `sim state` | Read the attached simulator's screen: the frontmost app and numbered elements with their centre points. |
| `sim tap` | Tap an element by number or label, or a point in device points. A duration makes it a long press. |
| `sim swipe` | Swipe between two points in device points. Starting at a screen edge makes a system gesture. |
| `sim type` | Type text into the focused field on the attached simulator. |
| `sim button` | Press a hardware button on the attached simulator. |
| `sim rotate` | Turn the attached simulator to an orientation and read its screen. |
| `sim screenshot` | Capture the attached simulator's screen at its size in points. |
| `sim launch` | Launch an installed app by bundle id, relaunching it if it runs, and read the screen. |
| `sim terminate` | Quit an app on the attached simulator by bundle id. |
| `sim install` | Install a built .app from inside the project on the attached simulator. |
| `sim open_url` | Open a URL or deep link on the attached simulator. |
| `sim touch_path` | Drag one finger through points over a duration, as a long-press drag or drawing. |
| `sim touch2_path` | Move two fingers through points together, to pinch, spread or turn. |
| `sim logs` | Read the attached simulator's log by cursor and generation, all of it or one process's. |
| `sim detach` | Let go of the attached simulator, for another agent to use. |
