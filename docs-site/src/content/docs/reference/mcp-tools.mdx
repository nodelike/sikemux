Every agent Sikemux starts gets these tools through the `sikemux-tools` MCP server. The same calls work from a terminal with `sikemux tool METHOD [JSON_PARAMS]`.

## browser

| Tool | What it does |
|---|---|
| `browser_navigate` | Open a URL or go back, forward or reload, then wait for the page. |
| `browser_state` | Read the tab: url, title, numbered elements, text, tabs and downloads. |
| `browser_find` | Find elements by visible text or accessible name. |
| `browser_click` | Click an element by number, text or selector, or a point. |
| `browser_type` | Type into a field, replacing its value, or at the caret. |
| `browser_press` | Press a key or chord, such as Enter or Meta+a. |
| `browser_act` | Run clicks, typing and keys in one call. |
| `browser_drag` | Drag from one element or point to another. |
| `browser_upload` | Give files to a file input. |
| `browser_dialog` | Answer the page's alert, confirm or prompt. |
| `browser_viewport` | Set this tab's viewport size or preset. |
| `browser_scroll` | Scroll to an element, by deltaY, or to an end. |
| `browser_evaluate` | Run a script in the page; returns JSON. |
| `browser_network` | List the page's requests with status and body. |
| `browser_console` | List the page's console messages and errors. |
| `browser_screenshot` | Capture the tab or the whole page. |
| `browser_annotate` | Draw a labelled box or caption over the page. |
| `browser_record` | Record this tab to MP4, or stop recording. |
| `browser_wait` | Wait for text, a selector, a url or a quiet network. |
| `browser_switch_tab` | Make one of this agent's tabs the current one. |
| `browser_close_tab` | Close one of this agent's tabs. |

## sim

| Tool | What it does |
|---|---|
| `sim_devices` | List the iOS simulators, the one you hold, and which other agents hold. |
| `sim_attach` | Attach a simulator by name or udid, else your project's own; boots it if needed and reads its screen. |
| `sim_state` | Read the attached simulator's screen: the frontmost app and numbered elements with their centre points. |
| `sim_tap` | Tap an element by number or label, or a point in device points. A duration makes it a long press. |
| `sim_swipe` | Swipe between two points in device points. Starting at a screen edge makes a system gesture. |
| `sim_type` | Type text into the focused field on the attached simulator. |
| `sim_button` | Press a hardware button on the attached simulator. |
| `sim_rotate` | Turn the attached simulator to an orientation and read its screen. |
| `sim_screenshot` | Capture the attached simulator's screen at its size in points. |
| `sim_launch` | Launch an installed app by bundle id, relaunching it if it runs, and read the screen. |
| `sim_terminate` | Quit an app on the attached simulator by bundle id. |
| `sim_install` | Install a built .app from inside the project on the attached simulator. |
| `sim_open_url` | Open a URL or deep link on the attached simulator. |
| `sim_touch_path` | Drag one finger through points over a duration, as a long-press drag or drawing. |
| `sim_touch2_path` | Move two fingers through points together, to pinch, spread or turn. |
| `sim_logs` | Read the attached simulator's log by cursor and generation, all of it or one process's. |
| `sim_detach` | Let go of the attached simulator, for another agent to use. |
