title: The agent board
description: "Cards your agents work from, and slices that only pass on evidence Sikemux collected itself."
---

Each project has a board of cards, open with `⌘⌥6`. You and your agents add cards, an agent claims one and works it, and a card can sit under another or wait on others. Agents use the `board_add`, `board_claim`, `board_update` and `board_list` tools.

The same work never gets two cards. A Jira or Linear ticket you put on the board again, while its card is still open, goes to that card, and so does a board trigger that fires again, with what came with it, such as a webhook's request. The card keeps the last eight such arrivals, and the agent working it, or its team's lead, is told. A ticket put on the board again after its card is done gets a new card, and its open subtasks move under it.

## Slices

A card that makes a **promise**, one sentence saying what it changes, is a slice. A slice goes up three gates before it is done:

| Gate | Who passes it | What it needs first |
| --- | --- | --- |
| **Built** | The agent that holds the card | The project's check passed on the agent's latest commit |
| **Looks right** | You | Built |
| **Landed** | Sikemux | Looks right, and the slice's commits on the branch |

An agent saying a slice is done passes nothing by itself. When it marks the card done, Sikemux looks at the latest check run on the agent's latest commit. If that run failed, or the agent committed nothing, the card stays in progress and the agent is told why. If the check has not run on that commit yet, Built passes by itself once it does, and the agent hears. Sikemux reads the agent's latest commit from git each time before Built passes, so a commit it didn't hear about can't slip through. A project whose `sikemux.json` names no `check` can't pass Built. The check is a command Sikemux runs, or the project's CI, which counts only once the agent's commit is on the project's branch and pushed; see [the project's check](/getting-started/projects/#the-projects-check).

A check command runs on commits on the project's branch, so an agent in a checkout of its own lands its commits before Built can pass; so does CI, once the project's branch is pushed. Work can land before you look at it; Landed passes as soon as you pass Looks right. A new commit on a slice that isn't done yet undoes Built and Looks right, so you never pass work you didn't see. Marking a slice done yourself passes every gate it has left, and moving it back to Open clears them.

## Cards Auto runs

When Auto takes a card, the card becomes a slice, promising what its title says unless it already makes a promise. Shipping its work counts as the agent saying it's done, and Built passes once the pull request's checks pass on the commit Auto pushed.

- When Auto merges the work itself once its reviewer approves, the card has no Looks right gate: it passes Built, then Landed when it merges.
- When Auto leaves pull requests for you to merge, the card waits for you at Looks right with its pull request. Merging it yourself passes Looks right as yours, and Landed follows.

When Auto gives a card back, the inbox says what it needs from you: something to fix, such as checks that failed again after a fix or a merge that didn't go through, or something only you can unblock, such as an agent that stopped running. **Ship it again** on the card starts Auto on it again.

## Evidence

Sikemux collects a slice's evidence itself:

- each run of the project's check on the agent's commits, with its output, passed or failed
- the change the agent's latest run of commits makes, once Built passes
- the browser recordings the agent makes while it works the card

A slice keeps its latest 24 pieces of evidence, and every piece you wrote a note on.

## When a slice needs you

A slice waiting at **Looks right** shows in the inbox as something to decide, with its promise and recordings, and in the board's **Needs you** column. Pass it once it looks right. If it needs more work, write a note on the slice, or on one piece of its evidence: the note goes to the agent whose work that piece shows, else to the agent that holds the card, as a message from you, and the slice waits at Looks right until the agent sends new work.
