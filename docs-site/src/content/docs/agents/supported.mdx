Sikemux runs the coding agent CLIs you already use. It finds them on your `PATH` and in the folders their own installers use.

| Agent | Chat in Sikemux | YOLO | Effort levels | Several accounts | Plan limits |
|---|---|---|---|---|---|
| [Claude Code](/each-agent/claude-code/) | Yes | Yes | low to max | Yes | Yes |
| [Codex](/each-agent/codex/) | Yes | Yes | minimal to max | Yes | Yes |
| [OpenCode](/each-agent/opencode/) | Yes | No | Not offered | No | No |
| [Hermes](/each-agent/hermes/) | Yes | Yes | none to ultra | No | No |
| [Pi](/each-agent/pi/) | Terminal only | No | off to max | No | No |
| [OMP](/each-agent/omp/) | Yes | Yes | off to max | No | No |
| [Grok](/each-agent/grok/) | Yes | Yes | none to max | No | No |
| [Muse](/each-agent/muse/) | Yes | Yes | minimal to ultra | No | No |

Each agent's page covers how to install it and sign in, how Sikemux runs it, and where Sikemux looks for it.

## How Sikemux talks to each agent

| Agent | In a chat, Sikemux runs |
|---|---|
| Claude Code | `claude` over its stream-json control protocol, the one Anthropic's Agent SDK uses |
| Codex | `codex app-server`, Codex's JSON-RPC server |
| OpenCode, OMP, Hermes | `opencode acp`, `omp acp`, `hermes acp`: the Agent Client Protocol |
| Grok | `grok agent --no-leader stdio`, one process per chat |
| Muse | `muse serve`, Muse's session protocol |
| Pi | No chat: Pi runs in its own terminal |

## Where Sikemux looks

Sikemux finds an agent on your `PATH`, and in `~/.local/bin`, `~/Library/pnpm`, `~/.npm/bin` and `~/.bun/bin`, plus each agent's own folder: `~/.claude/local` and `~/.claude/bin` for Claude, `~/.opencode/bin` for OpenCode, `~/.grok/bin` for Grok, and the ChatGPT app for Codex. Before using one, it checks that the program runs.

An agent that isn't installed shows **Not installed** on the welcome screen and in **Settings → Installed**, with an **Install** button, which runs the agent's own installer in a terminal you can watch. It installs where the agent's own updater expects, so the CLI works in your own terminal too. One that is signed out offers **Sign in** there, which runs the agent's own sign-in the same way, and one that is installed but won't run offers **Reinstall**.
