---
title: Model providers
description: "Run chats on a model provider's API key instead of an agent's own account, and add any OpenAI-compatible provider by its base URL and key."
---

An agent normally runs on its maker's account: Claude on Anthropic's, Codex on OpenAI's. A chat can run on a model provider instead, such as OpenRouter, DeepSeek, Groq, a coding plan, Ollama or LM Studio on this host, or any provider with an OpenAI-compatible API.

## Picking a model

The model picker in a chat lists the models of the agent picked above them, by provider: the agent's own account first, headed by its maker, then each provider you connected that the agent can run, then **+ Add provider**. Pick another agent to see what it runs: Claude lists Anthropic's models and Ollama's, OMP and OpenCode list every provider with a chat completions API.

Each model shows its context size, its price per million tokens and whether its tool calls work with agents, when Sikemux knows them. Models served on this host are headed with **local**.

Above the models, every chat agent sits in one row. One this host doesn't have is dimmed: click it to install it with its own installer.

Once a chat has started, it keeps its agent and provider, and the picker lists only the models it offers there.

## Adding a provider

**+ Add provider** asks for three things, as the provider's own dashboard gives them:

- **Base URL**, such as `https://api.lithosai.cloud/v1`. A URL copied with an endpoint on the end, such as `/chat/completions`, is cut back to its base.
- **API key**, which the field hides as you type. A model server on this host needs none.
- **Name**, filled in from the URL's domain. Change it if you like.

Sikemux asks the provider for its models to check the key. It shows how many models the provider serves before you add it. Added from a chat that hasn't started, the provider takes the chat with it: the chat moves to the agent that runs the provider, on its first model.

A URL Sikemux already knows, such as OpenRouter's, connects that provider. Any other URL is added as a provider of your own. The key is kept in the macOS Keychain and handed only to the chats that run on that provider. Removing a provider you added takes its key out of the Keychain too.

## Which agent runs it

Each provider runs with the agent that speaks its API:

| The provider serves | It runs with |
|---|---|
| Anthropic's Messages API | Claude Code |
| OpenAI's Responses API | Codex |
| Only chat completions | OMP, or OpenCode |

When that agent isn't installed, Sikemux installs it with the agent's own installer as soon as the key checks out, and you can add the provider while it runs. A message you send before the install ends waits in the draft, under "Waiting for OMP to finish installing…", and goes by itself once it does. If the install fails, the chat says so, with a link to the installer's output.

OMP and OpenCode can run any provider. Sikemux tells them of it for that one chat: your own OMP and OpenCode settings, sign-ins and models stay as they are.

## Providers in settings

Settings lists the providers Sikemux knows on three pages:

- **Coding plans**: monthly plans made for coding agents.
- **API providers**: hosted models you pay for by the token. **Add provider** at the end opens the same paste as the model picker.
- **Local models**: Ollama or LM Studio on this host. They need no key, and nothing leaves this host.

A provider you haven't connected offers **Get a key**, which opens its site, and **Add key**. A connected one says which agents can run it and the model it starts on, and **Check tool calls** tries whether its models work with agents. **Disconnect** forgets a known provider's key, and **Remove** takes away one you added by its URL, key and all.

## Helpers

When an agent starts another agent without naming a model, the new one runs as **Settings → Helpers** says: as the agent that started it, or as an agent you pick, paid by its own account or by a provider you connected, on the model you type. Claude Code's own subagents take that model too. The agent you work with keeps the model you picked.
