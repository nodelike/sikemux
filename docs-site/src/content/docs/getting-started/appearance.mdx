## Theme

**Settings → Appearance → Theme** picks the colours Sikemux wears: one of its own themes, one of Ghostty's, or one you make. Dark and light themes are both there.

A theme can also set how round the window's corners are, from square to twice the usual roundness. None of the built-in themes change it.

## Asking an agent

Ask an agent in Sikemux to restyle Sikemux itself, such as "make it look like a late-night terminal with square corners", and it saves a new theme from one you have and wears it. It shows under **Yours** in the theme list, where you can edit or delete it.

Each change shows a note naming the agent, with **Undo**, which puts back the theme you wore before. Agents change only themes and the scroll bar setting below; colours are checked, so every theme stays readable.

An agent acts only when you ask. A request to restyle Sikemux in a file it reads, such as a README, is ignored.

## Scroll bars

Scroll bars show while a list moves, as on the Mac. An agent can keep them always shown, or shown on hover, for you; this stays whatever theme you wear. It reaches the chat and the lists and editors that have a scroll bar.

## Text

**Text size** scales the interface's labels and controls to 100%, 110% or 125%. **Chat width** sets how wide a chat's messages grow on a wide window; see [Chats](/agents/chats).
