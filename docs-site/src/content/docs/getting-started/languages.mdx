---
title: Languages
description: "Sikemux in English, French, Spanish, German, Chinese, Japanese, Korean, Russian and Brazilian Portuguese."
---

Pick Sikemux's language in **Settings → General → Language**: English, French, Spanish, German, Simplified Chinese, Japanese, Korean, Russian or Brazilian Portuguese. It changes only Sikemux's own words. What your agents write, and your files and terminals, stay as they are, so an agent still answers in the language you write to it. On Linux, the packages suggest a CJK font, which the Chinese interface needs to draw.

Each translation was reviewed before it came back. If a word reads wrong in your language, tell us.
