## Moving between areas

**F6** moves the keys to the next area of the window: the side rail, the view in front (a chat's message box or a terminal), then the tab rail. **Shift+F6** goes back. A closed rail is skipped.

## The rails

While a rail has the keys, **↑** and **↓** move between its rows, and **Home** and **End** go to the first and last. A ring shows the row you are on, and the rail scrolls to keep it in view. **Return** or **Space** opens it, as a click would: a project, a page of its tree, a terminal, an agent or an earlier chat. **Shift+F10** opens its menu, and **Esc** gives the keys back to the view in front.

## VoiceOver

Rail rows are named for VoiceOver, which follows the row the keys are on.

VoiceOver hears the chat in front as its turn runs. **Settings → Chats → Screen reader** sets how much:

- **Status only** says when a turn starts, when it needs you, when it waits, and when it is done, stopped or failed.
- **Status and messages** also reads each message the agent finishes and then keeps working after. A very long one is cut short. The reply that ends the turn is not read: you hear **Done** and read it yourself.
- **Everything** adds the step the agent is on, such as the command it runs. Steps are spaced out, so a quick one can be skipped for the next.

The agent's thinking is never read.
