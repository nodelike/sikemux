The first time Sikemux opens it shows a welcome screen with four ways in:

| Move | Shortcut | What it does |
|---|---|---|
| Open a project | `⌘O` | Pick a folder or repository to work in |
| Start an agent | `⌘N` | Start a coding agent in a project you pick |
| Browse commands | `⌘⇧P` | Search every action and its shortcut |
| Connect to a host | `⌘⇧S` | Hosts from your SSH config |

If `git` is not installed, the welcome says so, since the Git view needs it. Press `esc` to skip it. You can see it again from the command deck (`⌘⇧P`, then **Show welcome**) or from **Settings → About**.

## Agents on this machine

Below the moves, Sikemux lists the coding agents it found on your computer and whether each is ready:

- **Ready**: installed and signed in.
- **Signed out**: installed, but its CLI has no sign-in yet. Click **Sign in** to run the agent's own sign-in.
- **Not installed**: Sikemux can run the agent's own installer for you. Click **Install** to watch it run in a terminal, then Sikemux looks for the agent again.
- **Not working**: installed, but it fails to start. Click **Reinstall** to run its installer again.

The same list, with the same buttons, is under **Agents on this host** in **Settings → Installed**. The agent palette (`⌘⇧N`) also offers **Sign in to** a signed-out agent beside starting it.

See [Supported agents](/agents/supported/) for the list.
