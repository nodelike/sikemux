---
title: First launch
description: "The two-step setup: a working agent, then your projects. Skipped when an agent is already signed in."
---

The first time Sikemux opens it walks you through a short setup: **Agents**, then **Projects**. The steps are required, and quitting midway brings the setup back next launch.

If an agent is already installed and signed in, and its saved chats name folders you work in, there is no setup: Sikemux adds the suggested projects (or your most recent one), opens a new chat in the first on that agent, and lists the project's past chats in the side rail to pick up where you left off.

The left half of the window welcomes you, says where you stand and holds the button that moves on. The right half is the step. The first time it appears the Sikemux mark resolves in over a moment, and any key skips that.

Tab and the arrows move between tiles and rows, Space ticks a project or runs an agent's action, and Return continues. If `git` is not installed, the setup says so, since the Git view needs it.

## Agents

Each agent Sikemux can set up gets a tile saying where it stands: **Ready**, **Installed**, **Signed out**, **Not installed** or **Won't start**. The step needs one agent that works; **Continue** becomes available as soon as one does. You can change which agent a chat uses later, in its composer.

No Claude or Codex plan? OpenCode's tile reads **Not installed · free**: **Install** it and it is **Ready · free models**, with no account or key, so you can Continue and chat straight away. Its free models change often and some of their providers keep your prompts to improve them, which the tile says.

A tile that needs something offers it: **Install** and **Reinstall** run the agent's own installer, and **Sign in** runs its own sign-in, in a terminal under the tiles where you can watch it. If one fails, the left half says why and **Try again** appears on the tile. With the keys on a tile, Return runs what it offers and the left half shows the exact command first; on a tile with nothing to do, or with no tile picked, Return continues. **Check again**, offered while no agent works, reads every agent's status afresh, which also happens when you come back to the window.

If an install or sign-in ends and still no agent works, for example on a machine with no network, **Continue anyway** appears so you are never locked out.

The same list, with the same buttons, is under **Agents on this host** in **Settings → Installed**. The agent palette (`⌘⇧N`) also offers **Sign in to** a signed-out agent beside starting it.

See [Supported agents](/agents/supported/) for the list.

## Projects

Sikemux offers the folders your agents have worked in, read from their saved chats. Repositories come first, newest activity on top, with clones of one remote side by side and folders outside git last. A repository with at least three chats in the last 30 days starts ticked. Folders that no longer exist, linked worktrees, temporary folders and anything under `Downloads` are left out.

The field above the list narrows it as you type, and Return ticks the first match. To add a folder that isn't listed, use **Choose folder…**, or type or paste its path (starting with `/`, `~` or `.`) and press Return. At least one project has to be ticked to continue.

**‹ Agents** above the welcome goes back to the first step. Click it, or Tab to it and press Return.

**Open Sikemux** adds your projects, finishes the setup and opens a new chat in the first ticked project on the first agent that works, ready ones before those only installed,, ready to type in. If a project can't be added, the setup stays open and says which one. If you used **Continue anyway** and no agent works, it opens the app without a chat.

You can look at the setup again from the command deck (`⌘⇧P`, then **Show welcome**) or from **Settings → About**. Once you've finished it the first time, `esc` closes it.

## Later

After a chat's turn finishes for the first time with Sikemux in front, a note asks once for a star on GitHub. **Star** opens the repository; closing the note is enough to say no, and it never comes back.
