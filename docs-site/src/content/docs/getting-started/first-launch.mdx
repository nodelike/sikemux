title: First launch

---

The first time Sikemux opens it walks you through a short setup: **Agents**, **Projects**, then **Start**. The steps are required, and quitting midway brings the setup back next launch.

Tab and the arrows move between rows, Space ticks a project or runs an agent's action, and Return continues. If `git` is not installed, the setup says so, since the Git view needs it.

## Agents

Each agent Sikemux can set up gets a tile saying where it stands: **ready**, **installed**, **signed out**, **not installed** or **won't start**. Pick the one that should start your first chat, with a click, Tab or the arrows.

A tile that needs something offers it: **Install** and **Reinstall** run the agent's own installer, and **Sign in** runs its own sign-in, in a terminal under the tiles where you can watch it. If one fails, **Try again** appears on the tile. Return on a tile with an action runs it; Return on one that works continues with that agent.

If an install or sign-in fails and no agent works, for example on a machine with no network, **Continue anyway** appears so you are never locked out.

The same list, with the same buttons, is under **Agents on this host** in **Settings → Installed**. The agent palette (`⌘⇧N`) also offers **Sign in to** a signed-out agent beside starting it.

See [Supported agents](/agents/supported/) for the list.

## Projects

Sikemux offers the folders your agents have worked in, read from their saved chats. Repositories come first, newest activity on top, with clones of one remote side by side and folders outside git last. A repository with at least three chats in the last 30 days starts ticked. Folders that no longer exist, linked worktrees, temporary folders and anything under `Downloads` are left out.

To add a folder that isn't listed, use **Add folder…**, or type or paste its path (`~` works) and press Return. At least one project has to be ticked to continue.

## Start

Say what should get done first, pick the project and the agent from the chips, and press Return or **Start**. Sikemux adds your projects and opens a chat in that project with your message sent.

**Just open Sikemux** adds your projects without starting a chat. If no agent is ready because setup failed, it is the only way forward.

You can look at the setup again from the command deck (`⌘⇧P`, then **Show welcome**) or from **Settings → About**. Once you've finished it the first time, `esc` closes it.
