title: Open a project
description: "Projects, and the sikemux.json that adds actions and tasks to one."
---

A project is a folder: its editor, terminals, Git and search all work in that directory. Open one with `⌘O`, or from a terminal with the `sikemux` CLI:

```bash
sikemux .
sikemux src/App.tsx:42:5
```

Install the CLI from **Settings → CLI**.

Sikemux is also listed under **Open With** in Finder and in apps that use it, such as Raycast. A folder opens as a project, and a text file opens in the editor of the repository it belongs to.

## Moving around

Swipe sideways with two fingers on the trackpad to move between a project's tabs, one tab per swipe.

The rail on the right has three pages, picked from the icons at its foot or by swiping across the rail:

- **Agents**: the project's chats, then the earlier ones.
- **Terminals**: every terminal open in the project.
- **Files**: the files open in the editor, then the project's file tree.

## A folder with several repositories

When the project folder is not a repository itself but holds several, such as `backend/` and `web/`, the Git pane lists them. Star one, or pick it in the project's **Settings**, and it becomes the project's default: the Git pane opens it, the top bar shows its branch, the diff pane reviews it, and new agent worktrees are cut from it. When the folder holds only one repository, that one is used without asking. The choice stays on your Mac.

## Project settings

Each project has settings of its own, apart from the app's. Open them with **Settings** at the foot of the project's tree in the sidebar; `Esc` or going anywhere else in the project closes them.

**General**:

- **Default git repository**, for a folder with several repositories.
- **Language servers**: whether the project may start them. Turning this off stops the ones running.
- **Code hosts**: the repository and account picked by hand on GitHub, GitLab or Bitbucket. **Forget** goes back to the project's remote and your signed-in account.
- **Space**: which space lists the project in the rail.

**Agents** sets what new chats start with in the project, over the app's **Settings → Agents**:

- **Agent**: the one New chat (`⌘N`) starts.
- **Permissions**: Normal or YOLO. Chats started from your phone in this project follow it too.
- **Start in a worktree**: whether a new chat gets a branch of its own.
- **Accounts**: for an agent you are signed in to more than once, which account chats here use, such as a work account for work projects.

Anything left on **App default** follows the app's setting. These settings stay on your Mac and are not written into the project.

## Project config

Check a `sikemux.json` into a project to add actions, tasks and a preview to the command deck (`⌘⇧P`). Sikemux shows each command and asks before running it.

```json
{
  "version": 1,
  "actions": [
    {
      "id": "check",
      "label": "Run checks",
      "command": "pnpm check",
      "placement": "terminal",
      "contexts": ["project"]
    }
  ],
  "tasks": [{ "id": "dev", "label": "Dev server", "command": "pnpm dev" }],
  "preview": { "url": "http://localhost:5173", "command": "pnpm dev" }
}
```

Agents can start, read and stop these tasks too. Tasks keep running in Sikemux's background process while the window is closed.

## Quitting

Terminals, agents and tasks keep running when you quit, and come back where they were. **Quit and Stop Everything** (`⌥⌘Q`) ends them.
