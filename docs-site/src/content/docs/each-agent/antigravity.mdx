Antigravity is Google's coding agent, run as `agy`.

## At a glance

| | |
|---|---|
| Command | `agy` |
| Chat in Sikemux | Yes, and its own TUI |
| Permission modes | Normal and YOLO |
| Several accounts | Yes, picked by hand; one on Windows |

## Install

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

It installs to `~/.local/bin/agy`. **Settings → Agents** runs the same installer from its **Install** button.

## Sign in

`agy` keeps its own Google sign-in, and Sikemux never reads it. A chat opens on that sign-in. When `agy` is signed out and Google AI Studio is connected in **Settings → Models**, the chat signs in with that Gemini API key instead. Otherwise it offers `agy`'s own login in a terminal.

On a Mac or Linux you can [add more accounts](/agents/accounts/#add-an-account) and pick one for each chat. Adding one takes a single trip to the browser, with no code to paste; **Use a code instead** in the dialog signs in with a pasted code. Its models and efforts show as soon as it is signed in: while they are read the model picker says so, and if reading them fails it says why, with **Try again**. An added account keeps its sign-in as a file in a folder of its own, apart from the one `agy` already has, and a chat on it stops with the reason rather than run on another account. When an account runs out, the chat offers the others; it never switches by itself.

## How Sikemux runs it

A chat runs `agy acp`, the Agent Client Protocol. Its tool calls fold like other agents', and its subagents show as cards with their own work. The model picker shows each model's maker's mark, such as Gemini's on Gemini models and Claude's on Antigravity's Claude models. While a new chat starts, the picker shows the models it listed last time.

A message you send while `agy` works goes into the running turn, steering it, rather than waiting for the turn to end.

Under bypass, the chat answers `agy`'s permission asks itself, and the terminal runs `agy --dangerously-skip-permissions`.

## Limits

Antigravity's 5-hour and weekly limits show under **Limits** in the rail for each account, as `agy`'s own `/usage` prints them. The limit Antigravity's Claude and GPT models share reads **Claude and GPT · 5h** and **Claude and GPT · week**.
