Pi is a minimal terminal coding agent.

## At a glance

| | |
|---|---|
| Command | `pi` |
| Chat in Sikemux | No, it runs in its own terminal |
| Permission modes | Normal only |
| Effort levels | off, minimal, low, medium, high, xhigh, max |
| Several accounts | No |

## Install

```bash
curl -fsSL https://pi.dev/install.sh | sh
```

Pi needs Node 22.19 or later, and its installer can install Node for you.

## Sign in

Pi signs in from inside its own terminal. Start `pi`, type `/login` and pick a subscription or an API key provider. Sikemux has no **Sign in** button for Pi.

Sikemux checks Pi's sign-in with `pi auth check`: ready, not signed in, or credentials that no longer work.

## How Sikemux runs it

Pi has no chat view in Sikemux. Start one from **+ new Pi** in ⌘⇧N; it runs in its own terminal, where you use it as you would anywhere else. If Pi crashes, Sikemux starts it again on the same session, below its old screen. After it sleeps or Sikemux restarts, it starts again on its session when you next show its tab; one put to sleep while you are looking at it shows **Wake**. A message to a sleeping Pi, from you or from another agent, wakes it in its terminal and types the message in once Pi is ready. Pi's earlier sessions show in the tab rail's **Recent** and in ⌘⇧N, and can be pinned; opening one resumes it in a terminal. The phone app starts only agents with a chat, so it doesn't offer Pi.

## Skills

Sikemux hands Pi its skills library each time it starts it, alongside the skills Pi already has.
