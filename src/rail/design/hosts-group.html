3 · A row's ⋯ menu, and adding a server in one click

A Sikemux host offers what the core can run there, and its lock: whether a new device or host on your account waits for you there. A plain SSH host offers to become one: the installer runs over the SSH you already have, the host signs in to your account by itself (ADR 0018), and the row turns purple.

4 · A host is chosen as a project is

Clicking a host's row chooses it with the same lift a project gets, and only one row in the side rail is chosen at a time. The tab rail then lists every chat and terminal running on that host, from every project, each with its project under it; its scope tabs read test-ec2 | All projects. Choosing a project still lists its chats from every host (ADR 0017). On an SSH-only host the list is its open SSH terminals. Opening a row keeps the host chosen.
