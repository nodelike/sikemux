Other hosts in the app

The app reaches every host on the account (ADR 0017, 0018). Their chats and terminals sit under the project they belong to, beside this host's, with a quiet on <host> only when they run elsewhere. A project only another host holds gets its own row. The new rows start on the host of the focused chat or terminal and name it when it is not this one; the hosts themselves are one group in the side rail (hosts-group.html).
